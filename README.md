# 🎓 Learn Sphere – E-Learning Platform

## 📌 Project Overview
Learn Sphere is a full-stack E-Learning Platform developed to provide a seamless online learning experience for students and educators. The platform allows users to browse courses, enroll in programs, access learning content, and manage payments through a secure and user-friendly interface.

## 🚀 Features
- User Registration and Login
- Course Browsing and Enrollment
- Secure Payment Integration
- Student Dashboard
- Course Management
- Learning Content Access
- Responsive User Interface
- User Authentication and Authorization

## ⚙️ Installation

1. Clone the repository:
```bash
git clone https://github.com/your-username/learn-sphere.git
```

2. Navigate to the project directory:
```bash
cd learn-sphere
```

3. Configure MySQL database in:
```properties
application.properties
```

4. Build the project:
```bash
mvn clean install
```

5. Run the application:
```bash
mvn spring-boot:run
```

6. Open in browser:
```text
http://localhost:8080
```
